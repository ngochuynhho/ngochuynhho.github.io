Methods, interpretation & provenance

The reference uses the selected model’s reference predictions: model development, internal reference, external ADNI/STAC and other ethnicity, plus the fixed CHARGE MCI reference. Average model combines probabilities for each scan across all models. Counts describe unique scans.

Development scans include training exposure. External/reference cohorts may have contributed to domain adaptation or threshold selection. These displays are descriptive, not independent validation. Uploaded data must already use the same upstream harmonization and feature units: the app does not fit a new harmonizer.

Inference selects features in the saved order, rounds volumes to float32, applies the saved scale mode (including ICV division), and uses the selected model. Best model retains its saved threshold; Average model uses a 0.5 cutoff on the mean probability. Higher scores indicate a more DA-like pattern. DA denotes Dementia of Alzheimer; original AD labels are displayed as DA.

The MCI reference contains 5,590 of 6,988 source MCI rows (approximately 80%), sampled across cohort and five-year age bands. The remaining 1,398 rows are kept out of the MCI fits. Invalid-age, duplicate-scan and existing CN/DA-reference records are excluded from selection, and example-upload participants are reserved. Records can include repeated visits; the split is not independent participant validation.

Trend prediction compares absolute score differences from CN, MCI and DA trends at the same age. Straight trends use linear regression; curved trends use quadratic regression. Missing ages or exact ties leave the trend prediction unavailable and retain the original binary label as a fallback. Extrapolation beyond a group’s reference ages is flagged in the export.

Age-Z fits logit output ~ age in CN reference scans outside model development, divided by residual SD with n−2 degrees of freedom. This exploratory linear normalization does not establish that disease and ageing have been separated. It is fixed for each model option and unaffected by chart filters or uploads.
